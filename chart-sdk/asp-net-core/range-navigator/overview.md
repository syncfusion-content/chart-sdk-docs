# Overview in ASP.NET Core Range Navigator Control

RangeNavigator is a data visualization control. It allows you to scroll and navigate through the data. This control easily combines with other controls such as Chart, Data Grid, etc., to create rich and powerful dashboards.

## Key Features

* **Data sources** - Supports local binding and remote data source.
* [**Tooltip**](https://ej2.syncfusion.com/aspnetcore/rangenavigator/default#/fluent2) - Supports interactive features such as tooltip and animation.
* [**Lightweight**](https://ej2.syncfusion.com/aspnetcore/rangenavigator/lightweight#/fluent2) - Supports light-weight Range navigator to load in mobile device.
* [**Period Selector**](https://ej2.syncfusion.com/aspnetcore/rangenavigator/perioddefault#/fluent2) - Provides options to select the data over the custom period.
* **Axis Types** - Supports multiple axis and series types to plot the data.
