# Using ODataV4Adaptor with the React Chart component

This section explains how to connect the Syncfusion&reg; React Chart component to an ASP.NET Core OData V4 service by using the `ODataV4Adaptor` from the Syncfusion React `DataManager`.

The `ODataV4Adaptor` is useful when the Chart data is available from an OData V4 endpoint. It handles OData-formatted requests and responses, and helps the Chart retrieve remote data with minimal client-side code.

## Server Step 1: Create ASP.NET Core Web API project

Open a terminal in Visual Studio Code and run the following commands.

```bash
mkdir ReactODataBackend
cd ReactODataBackend
mkdir server
cd server
dotnet new webapi
```

Delete the default `WeatherForecast.cs` and `Controllers/WeatherForecastController.cs` files generated by the template so they do not interfere with the OData endpoint.

Install the ASP.NET Core OData package. Use the version that matches your project's `TargetFramework` (this sample uses `net9.0`).

```bash

```

## Server Step 3: Create the OData controller

Create a `Controllers` folder and add the following file.

**Controllers/OrdersController.cs**

```csharp
using Microsoft.AspNetCore.Mvc;
using Microsoft.AspNetCore.OData.Query;
using Server.Models;

namespace Server.Controllers
{
    [Route("odata/[controller]")]
    public class OrdersController : ControllerBase
    {
        private static readonly List<Order> Orders = new()
        {
            new Order { OrderID = 1001, CustomerID = "VINET", Amount = 120, ShipCountry = "France" },
            new Order { OrderID = 1002, CustomerID = "TOMSP", Amount = 180, ShipCountry = "Germany" },
            new Order { OrderID = 1003, CustomerID = "HANAR", Amount = 250, ShipCountry = "Brazil" },
            new Order { OrderID = 1004, CustomerID = "VICTE", Amount = 310, ShipCountry = "France" },
            new Order { OrderID = 1005, CustomerID = "SUPRD", Amount = 400, ShipCountry = "Belgium" },
            new Order { OrderID = 1006, CustomerID = "RICSU", Amount = 230, ShipCountry = "Switzerland" },
            new Order { OrderID = 1007, CustomerID = "WELLI", Amount = 150, ShipCountry = "Brazil" },
            new Order { OrderID = 1008, CustomerID = "HILAA", Amount = 280, ShipCountry = "Venezuela" },
            new Order { OrderID = 1009, CustomerID = "ERNSH", Amount = 350, ShipCountry = "Austria" },
            new Order { OrderID = 1010, CustomerID = "CENTC", Amount = 90, ShipCountry = "Mexico" }

        [EnableQuery]
        public IActionResult Get()
        {
            return Ok(Orders);
        }
    }
}
```

The `[EnableQuery]` attribute allows the OData endpoint to process query options such as `$top`, `$skip`, `$filter`, and `$orderby`.

## Server Step 4: Configure OData and CORS

Replace the contents of `Program.cs` with the following code.

**Program.cs**

```csharp
using Microsoft.AspNetCore.OData;
using Microsoft.OData.ModelBuilder;
using Server.Models;

var builder = WebApplication.CreateBuilder(args);

builder.Services.AddCors(options =>
{
    options.AddPolicy("AllowAll", policy =>
        policy.AllowAnyOrigin()
              .AllowAnyMethod()
              .AllowAnyHeader());
});

var modelBuilder = new ODataConventionModelBuilder();
modelBuilder.EntitySet<Order>("Orders");

builder.Services.AddControllers().AddOData(options =>
{
    options.Select()
           .Filter()
           .OrderBy()
           .Expand()
           .Count()
           .SetMaxTop(100);

    options.AddRouteComponents("odata", modelBuilder.GetEdmModel());
});

var app = builder.Build();

app.UseCors("AllowAll");
app.UseRouting();
app.MapControllers();

app.Run();
```

The `Properties/launchSettings.json` file included with the template configures the server to listen on `http://localhost:5232` by default. The `server.http` file at the project root can be used with the Visual Studio Code REST Client extension to test the endpoint.

## Client Step 3: Create the React Chart with ODataV4Adaptor

Open `src/App.js` and replace its content with the following code.

**src/App.js**

```jsx
import React from 'react';
import { DataManager, ODataV4Adaptor, Query } from '@syncfusion/ej2-data';
import {
  ChartComponent,
  SeriesCollectionDirective,
  SeriesDirective,
  Inject,
  ColumnSeries,
  Category,
  Tooltip,
  Legend
} from '@syncfusion/ej2-react-charts';

function App() {
  const chartData = new DataManager({
    url: 'http://localhost:5232/odata/Orders',
    adaptor: new ODataV4Adaptor(),
    crossDomain: true
  });

  const chartQuery = new Query().take(10).sortBy('OrderID');

  return (
    <div style={{ margin: '40px' }}>
      <h2>📊 Syncfusion React Chart with ODataV4Adaptor</h2>

      <ChartComponent
        id="orders-chart"
        title="Order Amount by Customer"
        primaryXAxis={{
          valueType: 'Category',
          title: 'Customer'
        }}
        primaryYAxis={{
          title: 'Amount'
        }}
        tooltip={{ enable: true }}
        legendSettings={{ visible: true }}>

        <Inject services={[ColumnSeries, Category, Tooltip, Legend]} />

        <SeriesCollectionDirective>
          <SeriesDirective
            dataSource={chartData}
            query={chartQuery}
            xName="CustomerID"
            yName="Amount"
            name="Orders"
            type="Column">
          </SeriesDirective>
        </SeriesCollectionDirective>
      </ChartComponent>
    </div>
  );
}

export default App;
```

The `DataManager` acts as the communication layer between the Chart and the OData endpoint. The `ODataV4Adaptor` handles the OData request and response processing. The `query` property limits the records and sorts the result before binding it to the Chart series.

The `DataManager` instance is passed **directly** to the `SeriesDirective.dataSource` — the React Chart component issues the OData request internally and renders the result. No `useState` or `useEffect` is required.

## Alternative: Fetch data manually using executeQuery

You can also fetch data manually and pass the result array to the Chart. The `DataManager` configuration is the same as in the main example; only the binding changes.

```jsx
import React, { useEffect, useState } from 'react';
import { DataManager, ODataV4Adaptor, Query } from '@syncfusion/ej2-data';

function App() {
  const [chartData, setChartData] = useState([]);

  const dataManager = new DataManager({
    url: 'http://localhost:5232/odata/Orders',
    adaptor: new ODataV4Adaptor(),
    crossDomain: true
  });

  useEffect(() => {
    dataManager.executeQuery(new Query().take(10).sortBy('OrderID'))
      .then((e) => {
        setChartData(e.result);
      });
  }, []);

  return (
    <ChartComponent primaryXAxis={{ valueType: 'Category' }}>
      <Inject services={[ColumnSeries, Category]} />
      <SeriesCollectionDirective>
        <SeriesDirective
          dataSource={chartData}
          xName="CustomerID"
          yName="Amount"
          name="Amount"
          type="Column">
        </SeriesDirective>
      </SeriesCollectionDirective>
    </ChartComponent>
  );
}
```

Use this approach when you want to preprocess the response before binding it to the Chart.

## Troubleshooting

**Chart does not display data**

Check the following:

* The OData server is running.
* The URL in the DataManager matches the server URL.
* The browser Network tab shows a successful request.
* The response contains a valid OData `value` array.

**CORS error in browser console**

If the browser blocks the request, ensure CORS is configured in `Program.cs`.

```csharp
app.UseCors("AllowAll");
```

Also ensure that `app.UseCors("AllowAll")` is called before mapping controllers.

## Summary
